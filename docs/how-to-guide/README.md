# PropMetrik How-To Guide

**The comprehensive real estate platform for the Ghanaian market.**

PropMetrik provides institutional-grade tools for valuations, project management, property management, deal/CRM management, data analytics, e-signatures, and more -- all within a single unified platform.

This guide walks you through every module, feature by feature, so you can get the most out of PropMetrik from day one.

## How to Use This Guide

- **New users**: Start with Chapter 01 (Authentication) and Chapter 02 (Dashboard) to get oriented.
- **Project managers**: Jump to Chapter 03 (Project Management) and Chapter 04 (Budget & Cost) for construction workflows.
- **Property managers**: Focus on Chapter 05 (Property Management) and Chapter 06 (Tenant Portal).
- **Valuers**: Begin with Chapter 07 (Valuations) and Chapter 11 (Data Hub).
- **Administrators**: See Chapter 13 (Admin & Compliance) for organization-level configuration.

> **Tip:** Each chapter includes annotated screenshots. The screenshots are located in the `screenshots/` subfolder of each chapter directory.

---

## Platform Requirements

- **Browser**: Chrome, Firefox, Safari, or Edge (latest two versions)
- **Internet**: Stable broadband connection recommended
- **Mobile**: Progressive Web App (PWA) support -- add PropMetrik to your home screen for offline access to key features
